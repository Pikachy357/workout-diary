# Workout Diary

Консольный дневник тренировок на Java — учебный pet-проект.

Цель — пройти путь от консольного приложения на чистой Java
до REST API на Spring Boot + PostgreSQL, покрытого тестами
и упакованного в Docker.

## Что умеет сейчас

- Ввод тренировки с клавиатуры: название, упражнения, подходы
  (вес, повторения, сложность, комментарий)
- Проверка каждого поля при вводе, с повтором запроса при ошибке
- Статистика тренировки: тоннаж, максимальный вес, средняя сложность
- Сохранение тренировок в текстовый файл `workouts.txt`
- Загрузка сохранённых тренировок из файла

## Структура

| Класс | Назначение |
|---|---|
| `Workout` | тренировка: дата, название, список упражнений |
| `Exercise` | упражнение: название, описание, список подходов |
| `ExerciseSet` | подход: вес, повторения, сложность, комментарий |
| `Describable` | интерфейс краткого описания объекта |
| `WorkoutStorage` | сохранение и загрузка тренировок из файла |
| `Main` | консольный ввод и запуск программы |
| `Lambdas` | учебные упражнения с лямбдами и Stream API |

Сущности связаны композицией: тренировка содержит упражнения,
упражнение содержит подходы.

## Формат файла

Каждая строка начинается с метки уровня, поля разделены `;`:

```
WORKOUT;2026-09-29;День ног
EXERCISE;Приседания;Приседания со штангой
SET;80.0;10;5;разминка
SET;100.0;8;7;рабочий
```

Символ `;` запрещён во вводимом тексте, чтобы не ломать формат.

## Запуск

```
javac -d out src/*.java
java -cp out Main
```

Или открыть в IntelliJ IDEA и запустить `Main.main()`.

## Что использовано

- ООП: классы, инкапсуляция, композиция, интерфейсы
- Коллекции: `List`, `ArrayList`
- Лямбды, `Predicate`, Stream API
- Исключения: валидация в конструкторах, проверяемые и непроверяемые исключения
- `Scanner` для консольного ввода
- `java.nio.file` (`Files`, `Path`) для работы с файлами
- `LocalDate` для дат

## Известные ограничения

- Название упражнения вводится вручную каждый раз, поэтому
  «Жим» и «жим лёжа» считаются разными упражнениями.
  Планируется справочник упражнений.
- Автотестов пока нет, проверка ручная.
